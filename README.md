# 📦 Sistema de Gestión de Inventario (Java CLI)

## 📝 Descripción
Este es un proyecto de consola desarrollado en **Java** para la gestión de inventario de productos. 
El objetivo de este proyecto es aplicar conceptos fundamentales de la Programación Orientada a Objetos (POO), manejo de colecciones, validación de datos y gestión de excepciones para crear una aplicación robusta y funcional.
